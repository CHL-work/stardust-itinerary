# Stardust icon assets

The active app-icon master is `stardust-app-icon-v3.png`. It simplifies the
approved Egypt travel artwork into a compact mark that remains readable at
browser-tab and phone-icon sizes.

The two approved luggage concepts are preserved unchanged in `archive/`:

- `stardust-luggage-concept-v1.png` — original rendered concept.
- `stardust-luggage-cutout-v2.png` — transparent-background concept.

Runtime sizes are generated from the active master and live in `public/icons/`,
the `public/stardust-*.png` files, and Next.js special icon files under
`src/app/`.
